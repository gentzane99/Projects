## CS250 – Computer Graphics II

Advanced course focused on the mathematical foundations and algorithms behind real-time 3D computer graphics.

The course covers the complete **graphics rendering pipeline**, which transforms 3D data into a 2D image displayed on screen. This pipeline is studied as a sequence of stages, where each stage produces input for the next one.

### Core Topics

- Real-time 3D graphics for applications such as games, simulators, and architectural visualization
- Graphics rendering pipeline:
  - **Application stage**:  
    - 3D object representation and modeling  
    - Animation systems  
    - User interaction  
    - Camera control and animation  
    - Dynamic object simulation  
    - Collision detection
  - **Transformation stage**:  
    - Coordinate space transformations  
    - Mapping from model space to viewport space
  - **Rasterization stage**:  
    - Conversion of geometric primitives into 2D screen images

This course provides a deep understanding of how modern real-time rendering systems operate from both a mathematical and algorithmic perspective.
