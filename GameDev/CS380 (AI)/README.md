## CS380 – Artificial Intelligence for Games

Course focused on the design and implementation of **game-specific artificial intelligence systems**, combining theoretical foundations with practical, production-oriented algorithms.

The course emphasizes the **game AI programmer mindset**, using case studies from commercial games to illustrate real-world problem solving.

### Core Topics

- Game AI architecture:
  - Finite state machines
  - Rule-based systems
  - Goal-based systems
  - Trigger systems
  - Smart terrain
  - Scripting systems
  - Message passing and AI debugging
- Agent behavior:
  - Movement and steering behaviors
  - Pathfinding
  - Emergent behavior
  - Agent awareness and perception
  - Agent cooperation and coordination
- World reasoning:
  - Terrain analysis
  - Planning systems
- Learning and adaptation techniques

Students implement core game AI algorithms and systems, focusing on practical solutions suitable for real-time interactive environments.
