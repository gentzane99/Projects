## CS120 – High-Level Programming I (C)

Foundational course focused on learning the C programming language and core programming concepts.

The course introduces:
- Control flow through statement grouping
- Decision making and case selection
- Iteration and procedural programming
- Basic data types and memory concepts
- Lexical conventions, syntax, and semantics of C

This course serves as the basis for all subsequent high-level programming courses and projects.
