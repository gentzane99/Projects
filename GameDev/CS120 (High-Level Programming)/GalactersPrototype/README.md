# GALACTERS – Final Project

Console-based arcade game developed in C as a final academic project.

The objective is to defeat all enemies while avoiding enemy contact and projectiles.

---

## Controls

- **A** – Move left  
- **D** – Move right  
- **G** – Shoot  

---

## Gameplay Rules

- Defeat all enemies to win the game.
- The player loses if:
  - An enemy touches the player
  - A super enemy (2 lives) touches the player
  - An enemy bullet hits the player

---

## Game Modes

At the start of the game, the player can choose one of the following modes:

1. **Practice Mode**  
   - Enemies do not shoot

2. **Easy Mode**  
   - Enemies can shoot

3. **Normal Mode**  
   - Two different types of enemies appear

4. **Hard Mode**  
   - The player starts with only one life

*(Press the corresponding number key — no need to press Enter)*

---

## Spaceship Types

The player can also choose a spaceship type:

1. **Normal Spaceship**  
   - Standard movement and shooting

2. **Speedy Spaceship**  
   - Moves twice as fast

3. **Healthy Spaceship**  
   - Grants one extra life

*(Press the corresponding number key — no need to press Enter)*

---

## Important Notes

- If an invalid key is pressed when selecting a game mode or spaceship, the game will close.
- The project runs in a Windows console environment.
