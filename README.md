# Projects

Este repositorio recopila proyectos de **desarrollo de videojuegos** y **desarrollo fullstack**, tanto académicos como personales.

El objetivo es mostrar mi evolución como desarrolladora, mi forma de estructurar proyectos y los distintos stacks y tecnologías que he utilizado.

## Game Development
Proyectos relacionados con la programación de videojuegos, centrados en lógica de juego, sistemas, gameplay y programación orientada a objetos.

Carpeta:
/GameDev

## Fullstack Development
Proyectos web que incluyen frontend, backend y lógica de aplicación, con especial foco en buenas prácticas y desarrollo moderno.

Carpeta:
/FullStack

## Notas
Cada proyecto está organizado de forma independiente y puede incluir documentación adicional según el caso.
